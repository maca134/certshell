How it works

OIDC login

Sign in through Pocket ID or any OIDC provider. Your IdP groups decide what you can reach.

Per-session certificates

A fresh key and a 15-minute cert for every terminal. One host, one login, no forwarding.

One-line enrollment

Hosts trust the CA through a script. Existing authorized_keys keep working, so you can't lock yourself out.

Access map in the UI

Admins map IdP group → host → login. No edits on the host after enrollment.

Audit log

Every login, cert and session is logged in the app and on stdout. sshd logs each cert's ID and serial too.

Hardened container

Non-root, read-only root filesystem, all capabilities dropped, strict headers and rate limits.

Quick start

cp -r examples/caddy certshell && cd certshell
cp .env.example .env     # set SSH_DOMAIN, ID_DOMAIN, OIDC_* ...
docker compose up -d

Generate your own config with the setup generator. Full walkthrough in the docs.
